## 🚀 30분 초간단 셋업 가이드 (Quick Start)

### Step 1. GitHub 원격 저장소 생성 및 푸시
현재 폴더의 코드를 본인의 GitHub 저장소에 업로드합니다.

```bash
git init
git add .
git commit -m "feat: 삼성 & 하이닉스 주식 브리핑 자동화 파이프라인 구축"
git branch -M main
git remote add origin https://github.com/hanjisubusiness22222/project3.git
git push -u origin main
```

---

### Step 2. GitHub Actions 권한 설정 (필수 1분 소요)
GitHub Actions 봇이 생성된 리포트와 README를 자동으로 커밋할 수 있도록 쓰기 권한을 허용합니다.

1. 본인의 GitHub 저장소 상단 메뉴에서 **[Settings]** 클릭
2. 좌측 메뉴에서 **[Actions]** ➡️ **[General]** 선택
3. 화면 맨 아래 **Workflow permissions** 섹션으로 이동
4. **"Read and write permissions"** 선택 후 **[Save]** 클릭

---

### Step 3. 즉시 실행 테스트 (수동 트리거)
스케줄(매일 16:00 KST)을 기다리지 않고 지금 바로 잘 돌아가는지 확인해 볼 수 있습니다.

1. 저장소 상단의 **[Actions]** 탭 클릭
2. 좌측 목록에서 **`Stock Daily Briefing (Samsung & SK Hynix)`** 워크플로우 클릭
3. 우측의 **[Run workflow]** 버튼 클릭 ➡️ **[Run workflow]** 실행
4. 약 20~30초 후 초록색 체크(`✔`)가 뜨며 `README.md`와 `reports/` 폴더가 자동 갱신됩니다.

---

### 🔔 (선택 사항) 디스코드 실시간 알림 연동
GitHub 저장소에 커밋되는 것 외에 스마트폰/PC로 실시간 알림을 받고 싶다면:

1. 디스코드 채널 설정 ➡️ 연동 ➡️ **웹후크 만들기** ➡️ 웹후크 URL 복사
2. GitHub 저장소의 **[Settings]** ➡️ **[Secrets and variables]** ➡️ **[Actions]** 이동
3. **[New repository secret]** 클릭
   - Name: `DISCORD_WEBHOOK_URL`
   - Value: `복사한 디스코드 웹후크 URL`
4. 이제 매일 장 마감 시 디스코드로 자동 브리핑 메시지가 도착합니다!
